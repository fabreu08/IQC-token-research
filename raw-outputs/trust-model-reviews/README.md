# Trust Model Reviews

This folder archives external model reviews specifically focused on the IQC Trust Model document.

## Purpose

The Trust Model is a foundational document. These reviews provide critical feedback on its completeness, clarity, and actionability before it is finalized as the canonical reference.

## Current Contents

- `grok-trust-model-review.txt` — Grok's structured review (using [AGREE]/[DISAGREE]/[NEW] format)
- `kimi-trust-model-review.txt` — Kimi 2.5's detailed narrative review

## Key Themes from These Reviews

- Strong emphasis on the need for **specific, named signers/entities** rather than generic "multisig" language.
- Criticism that the adversary analysis is still narrative rather than structured.
- Cross-contract interaction risks (Registry slashing + Allocation releases) are under-analyzed.
- The document is still too vague on emergency procedures and recovery.
- Several reviewers note that "transfer to multisig" is risk transfer, not risk reduction, without signer diversity and operational security details.

## Status

These are the first dedicated reviews of the Trust Model document (v0.2 Team Review Draft).

Additional reviews can be added to this folder as they are received.
